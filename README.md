# アオギリフォレスト合同会社 AI本部（オフライン試作品）

架空データを使い、リサーチ → 営業 → 経理財務を順に実行します。
Python 3.9以降と標準ライブラリだけで動きます。インストール、APIキー、インターネット接続は不要です。
この試作品の「AI担当」はルールベースの模擬処理です。LLMによる推論や実際の市場調査は行いません。

## 実行

このディレクトリで以下を実行してください。

```sh
python hq.py
python -m unittest discover -s tests -v
```

`artifacts/dashboard.html` をブラウザーで直接開くと日本語レポートを閲覧できます。
Webサーバーは不要です。`artifacts/result.json` に部門別の結果・案件ID・判断理由・処理件数が保存されます。

```sh
python hq.py --input data/demo.json --out artifacts
```

出力は同名ファイルに上書きされます。同じ入力は同じ結果になります。

## 部門の連携

1. リサーチ：架空の根拠を保持し、適合度の高い順に並べ、70点以上を営業へ渡します。
2. 営業：顧客課題から定型の提案草案を作成。架空予算を提案額とします。
3. 経理財務：粗利益率30%以上、先行支出後の資金50万円以上、入金60日以内を検査します。

財務審査通過案件は原価を資金から予約控除し、後続案件で同じ資金を再使用しません。
予約順は適合度降順、同点は案件ID順です。将来の入金を新規案件に再投資する最適化は行いません。
0日目に原価を全額支払い、指定日後に売上を全額回収する保守的な仮定で資金繰りを表示します。
審査通過は実際の受注・発注・送金を意味せず、すべて人間確認待ちです。

## 入力

`data/demo.json` は全件架空です。`fictional: true` が必要です。
`opening_cash_yen` は初期資金、`minimum_cash_yen` は最低手元資金、
`minimum_margin_percent` は最低粗利益率です。
各案件には一意のID、企業名、課題、根拠、適合度（0〜100）、予算円（正整数）、原価円、入金日数（非負整数）を指定します。
金額は整数円で処理し、判定は丸め前の整数比較、表示利益率だけ小数第2位に丸めます。
入力の重複ID・欠落・不正な値はエラーとして終了します。

## ファイル

- `hq.py`：各部門、連携制御、入力検証、HTML/JSON出力、CLI
- `data/demo.json`：架空の4社と仮定
- `tests/test_hq.py`：連携、財務、境界値、異常系、CLI、通信禁止、HTMLエスケープの検証
- `REPORT.md`：日本語の実行結果

## 対象外

外部への調査・メール・CRM接続・銀行接続・公開は実装していません。
HTMLは外部リソースを読み込まず、CSPでも外部読込みを禁止しています。
会計部分は粗利益と簡易資金繰りの試算であり、消費税、固定費、仕訳、税務申告、貸倒れは扱いません。
公開リポジトリのため、実顧客情報・APIキー・社内財務数値は保存しないでください。

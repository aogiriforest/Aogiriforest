# 協力先・商品を後から追加できる登録設計 v1.0
2026-10-26

## 方針
最初に和菓子・納豆・農家などを固定登録しない。協力先と商品は必要な時点で追加し、営業企画・リサーチ、プレゼン制作、広報が共通参照する。未登録でもテンプレートとワークフローは利用可能。

## データの関係
協力先（PARTNER）1件に、複数の店舗（LOCATION）、生産者（PRODUCER）、商品（PRODUCT）、取材記録（INTERVIEW）、コンテンツ案件（CONTENT_JOB）を関連付けられる。商品は複数協力先と関連付け可能。協力先の種別は農家、飲食店、和菓子店、食品メーカー、卸、その他の拡張可能な分類。

## 登録項目
協力先: ID、名称、種別、地域、公開情報URL、窓口（非公開）、協業状態、取材可否、情報利用許諾。
商品: ID、名称、関連協力先、商品分類、原料、製造工程、動物性・五葷・アルコール基準の確認状態、有機認証、価格・ロット（非公開）、写真権利。
コンテンツ案件: ID、対象協力先・商品、目的、媒体、確認済み事実と出典、未確認事項、制作状態、承認状態、公開URL。

## 指示例
- 「新しい農家さんを登録して」→登録に必要な最小情報だけ確認
- 「このお店のこだわりを調べて」→公開情報を調査し、未確認点を整理
- 「この商品のnote下書きを作って」→営業企画調査→取材質問→ストーリー→広報編集→品質確認
- 「今は登録だけ」→制作も公開もしない

## 情報管理・承認
実名の協力先情報、個人情報、取引条件は公開GitHubに記録しない。取材の外部連絡、記事公開、DM送信は代表承認が必要。未検証の希少性や認証等を断定しない。

# アオギリフォレスト AI本部：Google Sheets連携版

既存の `aogiri_ai_mobile_dashboard.html` とREADMEは変更しません。このフォルダは別画面として追加するための実装です。顧客・財務データ、会話、台帳ID、認証情報は含みません。

## 今回用意した機能

- iPhoneのSafariで利用する、Googleログイン必須・所有者限定の画面。
- 会話からChatGPTが整理したJSONを貼り付け、編集→全項目確認→承認保存。
- 承認前の入力は画面内のメモリのみ。保存前に外部サービスへ送信しません。
- 営業案件、経理明細、月次実績、承認履歴を非公開スプレッドシートに保存。
- 複数シートと承認履歴を1回のSheets API呼出しで原子的に保存。通信断の再試行は承認IDで重複を防止。
- 同じ取込キーの追加を拒否。既存の月次実績を上書きしません。
- 旧HTMLのJSONバックアップを読込み、内容を確認して追加取込。
- 承認済みの数字を再読込して表示。朝報履歴の直近7件を表示。

AI秘書・部長AIはChatGPT上の役割分担です。このコード自体に有料AI APIの呼出しはありません。すべてのChatGPT会話を自動取得する機能や、既存Sitecaseファイルとの自動同期はありません。

## 初回設定：Google側で必要な操作

この手順は、チャットで渡された非公開台帳の所有者が行います。シートのリンクやIDを公開GitHubへ貼り付けないでください。

1. 作成済みの非公開台帳を開きます。PCまたはiPadのブラウザでの初回設定を推奨します。iPhoneのみの場合はSafariの「デスクトップ用Webサイトを表示」を利用しますが、エディタ操作に制約があります。
2. 「拡張機能」→「Apps Script」を開きます。既存のスクリプトがある場合は上書きせず、まず内容を確認してください。新しい台帳では通常空のプロジェクトが開きます。
3. `Code.gs` の内容を貼り付けます。HTMLファイルを追加し、名前を `Index` として `Index.html` の内容を貼り付けます。
4. プロジェクトの設定で「appsscript.json マニフェスト ファイルをエディタで表示する」を有効にし、このフォルダの `appsscript.json` を設定します。高度なGoogleサービスのSheets API v4が有効になります。標準GCPプロジェクトを利用している場合はGoogle Cloud側のSheets API有効化も必要です。
5. `setup` を一度実行し、Googleの権限確認を完了します。自分の非公開台帳に対するスプレッドシート権限と本人メールアドレスの確認を利用します。Googleログインの承認は所有者本人による操作が必要です。
6. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」。実行ユーザーを「自分」、アクセスできるユーザーを **「自分のみ」** にします。「全員」や匿名公開を選ばないでください。
7. 発行された `/exec` URLを、同じGoogleアカウントでログインしたiPhoneのSafariから開きます。必要ならSafariの共有メニューからホーム画面へ追加します。
8. 初回は「台帳を再読込」で未登録状態を確認します。実データを使うときに、内容確認→承認保存→台帳読戻しまで確かめます。

台帳の共有は「制限付き」のままにします。画面はGoogle認証と所有者チェックの両方を使用します。メールアドレスを取得できないアカウント構成では、公開範囲を緩めず設定を確認してください。

## 日々の操作

1. ChatGPTに画面内の整理用指示文と対象の会話を渡します。不明な必須項目は推測せず質問してもらいます。
2. JSONを連携画面に貼り付け、必要なら修正します。sourceに会話題名や日付を記載します。
3. 「内容を確認」で全項目を表示し、確認チェック後「承認して保存」を押します。
4. 自動再読込で反映を確認します。未承認の下書きを保存する機能はありません。ページを閉じると入力は失われます。

sourceKeyは出典内で一意のレコード識別子です。同じ事実の再取込には同じキーを使います。異なる取引には別のキーを付けます。キーなしでは同一内容を重複とみなします。保存済み行が含まれるバッチは、丸ごと保存を拒否します。行を除いて再確認してください。

初期版は追加登録用です。営業進捗の更新や保存済み取引の修正は、台帳で対象の記録IDを確認して手動対応します。sourceKeyを変えて同じ案件を追加しないでください。修正を含む厳密な変更履歴・取消処理は今後の拡張です。台帳を直接編集するとアプリの承認手順を通らないため、通常登録は連携画面を使用してください。

月次実績は1か月1件です。経理明細と月次実績を二重加算しません。入出金予定と売上・経費も分けて記録します。残高データがない状態で資金残高を推計しません。

## 既存HTMLの活用

旧HTMLの「バックアップを書き出す」でJSONをiPhoneの「ファイル」に保存します。新画面のバックアップ取込で選び、内容を確認してから追加保存してください。元のHTML、localStorage、バックアップは保持します。

旧形式には案件IDがないため、移行時は行位置を識別キーに使います。並べ替えや削除をした異なるバックアップを再取込する場合は、既存案件と照合してください。一括再移行より、差分をJSONで整理する運用を推奨します。

## 毎朝06:00（Asia/Tokyo）の朝報

既存のChatGPT「アオギリフォレスト AI秘書朝報」タスクを台帳参照型に更新しました。新しいタスクを重複作成する必要はありません。Apps Scriptの時間トリガーは作成しません。

タスクは承認日時のあるデータを読み、営業・経理・今日の優先業務をまとめ、結果をタスク内へ報告します。朝報履歴にも保存し、同日の再実行では重複行を作成しません。接続が切れていたら未連携と表示し、数値を補完しません。

06:00に実行する指定です。生成・Google API・通知処理の時間があるため、06:00:00ちょうどの作成完了・通知配信は保証できません。初回の定期実行はまだ未検証です。通知を受けるにはChatGPT側の通知設定も必要です。

## 費用と状態

初期版では追加のAI API料金は発生しません。Google Apps Script／Sheetsは利用枠・割当の範囲内で動作します。ChatGPTの契約・タスク利用上限は別途適用されます。

ローカルのテストでは入力検証、日付、重複拒否、承認ID再試行、書込み失敗時の整合性、本人チェック、HTMLのJavaScript構文を検証しています。実際のGoogleウェブアプリのデプロイと、iPhoneでの承認保存は未実施です。
